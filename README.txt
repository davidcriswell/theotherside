THE OTHER SIDE WEBSITE STARTER

Files: index.html, styles.css, script.js, assets/*.jpg

Deploy via Cloudflare Pages (Direct Upload):
1. Sign into Cloudflare dashboard.
2. Go to Workers & Pages, create a Pages project, choose Direct Upload.
3. Name the project theothersideofficial (if available).
4. Upload this site's ZIP or the contents of the site folder, depending on the upload prompt.
5. Deploy and visit the provided *.pages.dev URL.

Note: the ZIP contains the site files at its root, not in an extra nested folder.
